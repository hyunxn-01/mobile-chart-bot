## 읽는 법

- **종류** (a) 로그인 없이 열리는 실제 대시보드 · 공개 데모 · 제품 둘러보기 / (b) 대시보드 화면 사진이 있을 것으로 보이는 제품 소개 · 도움말 · 사례 페이지 / (c) 대시보드 화면이 나오는 영상(또는 영상이 실린 페이지)
- (a) 중 로그인 · 이메일이 필요할 수 있거나 확인하지 못한 곳은 근거 칸에 적었습니다. (b)는 페이지 종류로 분류한 것이며 사진이 실제로 있는지는 열어 봐야 압니다.
- **근거 문장**: '한눈에 보는 모니터링 화면'이라는 근거로 검색 결과에 나온 문장을 따옴표로 옮겼습니다. 검색 도구가 보여 준 요약문 속 문장이라 원문과 조금 다를 수 있습니다. 없으면 '근거 없음'.
- **열람**: GitHub README 이미지를 내려받아 직접 본 것만 '열람'입니다. 나머지는 모두 '미열람'입니다.
- **이미지 주소**: 검색 결과에는 png · jpg · webp 직접 주소가 하나도 나오지 않았습니다. 이미지 주소는 GitHub README에서 확인한 것만 있습니다.

## 수집 방법과 한계

- 이 클라우드 환경은 GitHub 밖 웹사이트를 열 수 없어서(WebFetch 접속 차단) 웹 검색 결과의 제목 · 주소 · 요약문만으로 목록을 만들었습니다.
- GitHub(raw.githubusercontent.com)은 열려서 오픈소스 대시보드 README 이미지는 직접 열어 봤습니다. 다만 README 이미지가 외부 서버에 있는 곳(Countly 등)은 막혀서 보지 못했습니다.
- 예전 `site-candidates*.md`는 참고하지 않았습니다. 소비자용 순위 화면, 매체 기사, 개념 디자인 시안은 넣지 않았습니다(근거 문장만 기사에서 가져온 곳은 근거 칸에 출처를 밝혔습니다).
