# KPI 지표형 × AI 분석 강조 대시보드 견본 20

본 화면(`docs/*.html`)과 분리된 탐색용 견본이다. 기존 화면의 배치 · 색 · 글꼴은 참고하지 않았고, 데이터 구조만 확인했다.

## 여는 법

```bash
python3 -m http.server 8000
```

저장소 루트에서 위 명령을 실행하고 `http://localhost:8000/mockups/`를 연다(비교 목록 `index.html`). 견본은 `../docs/markets/`의 실제 JSON을 상대 경로로 읽으므로, 파일을 직접 더블클릭해 열면(file://) 데이터를 읽지 못한다.

## 들어 있는 것

| 경로 | 내용 |
|---|---|
| `research/sources.md` | 조사 출처 80건(열람 25 · 검색 결과만 55)과 막힌 주소 |
| `research/taxonomy.json` | 조사에서 정한 분류 축 11개와 값 정의, 대시보드 74개의 요소 · 분류 값 |
| `plan.json` | 견본 20개 설계(개념, 분류 값 조합, AI 강조 방식, 데이터 파일)와 서로 다른 정도(두 견본 사이 최소 4개 축 차이) |
| `01-…html` ~ `20-…html` | 견본. 빌드 없이 열리는 단일 HTML, 외부 라이브러리 없음(차트는 직접 그린 SVG) |
| `index.html` | 20개 비교 목록(이름 · 개념 · 분류 값 · 링크 · 화면 사진 · 분류 값 표 · 차이 행렬) |
| `screenshots/` | 확인 때 찍은 화면 사진(데스크톱 1440px 전체 페이지, 모바일 390px 첫 화면) |

각 견본 HTML 안의 `/*MK-CORE-BEGIN*/ … /*MK-CORE-END*/` 구간은 20개가 똑같이 쓰는 공통 도우미(데이터 읽기, 브리핑 글 나누기, 작은 SVG 차트)다.

## 확인 결과 (2026-10-31)

Playwright(Chromium)로 정적 서버에서 21개 페이지(견본 20 + 목록)를 데스크톱 1440×900, 모바일 390×844로 열었다.

- 21개 모두 데이터 로딩 완료 신호(`data-mk-ready=ok`)를 냈고, 데이터 오류 상자가 뜨지 않았다.
- 콘솔 오류 0, 페이지 스크립트 오류 0, 로컬 파일 요청 실패 0.
- 390px 폭에서 가로 스크롤이 생기는 페이지 0.
- 각 견본을 만든 작업자가 탭 · 필터 · 클릭 같은 주요 조작을 눌러 보고 오류가 없음을 확인했다(전 조작을 자동 시험한 것은 아니다).

## 확인하지 못한 것 · 한계

- **앱 아이콘**: 작업 환경의 네트워크가 App Store 이미지 서버(`is1-ssl.mzstatic.com`)를 막아 아이콘이 화면 사진에 빈칸으로 나온다. 아이콘이 실제로 보이는 모습은 확인하지 못했다(실패하면 빈칸으로 남도록 처리함).
- **브라우저**: Chromium에서만 확인했다. Safari · Firefox는 확인하지 못했다.
- **규칙 기반 추출**: 권고 문장의 우선 · 관망 · 보류 신호(07 · 17), 문장 속 게임 · 장르 이름 찾기(03 · 04 · 10 · 13 · 16 · 17 · 19), 흥미도 점수(02), 예상 범위(05)는 사람이 정한 규칙이다. 각 견본 화면에 규칙을 적어 두었고, 틀린 연결이 있을 수 있다.
- **12 브리핑에 묻기**: 실시간 AI가 아니라 Claude가 이미 쓴 브리핑을 낱말로 찾아 모은다(화면에도 적음).
- **조사**: 상용 도구 페이지는 네트워크 정책으로 열지 못해 검색 요약에 기대었다(`research/sources.md` 참고).
